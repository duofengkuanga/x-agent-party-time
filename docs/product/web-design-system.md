# Web 产品设计系统

本文件定义 Agent Party Time 用户页面的长期设计语言。强制执行摘要位于 `apps/web/AGENTS.md`；修改或新增用户界面前必须同时遵守两者。

## 信息组织

- 页面必须根据当前角色、当前任务、内容关系和操作频率组织，不套用通用 Dashboard、后台模板或固定页面原型。
- 一屏保持一个清晰的主操作层级，只展示完成当前任务必需的信息和操作，不通过装饰性容器制造虚假层级。
- 高频与低频操作按照“当前角色 + 当前页面任务”判断。高频操作就近、直接、少步骤；低频操作不抢占主工作区，但必须有明确入口。
- 技术细节、诊断信息和低频管理信息渐进披露；空状态只提供最合理的下一步。
- 删除、撤销等低频高风险操作必须说明后果并要求确认。
- 用户已经确认的具体交互是产品约束；未经再次确认，不改变其信息关系、操作路径或反馈方式。

## 视觉语言

- 保持工业纸张控制台气质：暖灰纸张、黑色墨水、珊瑚强调色及对应夜间主题。
- 使用硬边框、克制的错位阴影和细颗粒纸张纹理。
- Georgia 斜体只用于品牌或重点展示，等宽字体承担主要信息表达。
- 页面一致性来自共同的视觉变量、交互规则和设计原则，不来自复制相同页面结构。
- 不引入紫蓝霓虹、玻璃拟态、柔软圆角 SaaS 卡片墙或另一套视觉体系。

## 界面语言

- 除品牌名称、品牌标语和登录页固定文案 `the agents is having a party` 外，面向用户的界面文案使用中文。
- 技术术语、状态、操作名称和提示语优先使用准确中文，不为了装饰或营造“产品感”夹杂英文。
- 内部英文枚举、协议术语和数据库术语必须转换为用户能够理解的中文表达。
- 用户自行输入的内容和内部代码标识不受界面语言限制。

## 按钮与操作状态

- 所有按钮和视觉上作为按钮使用的链接复用统一语义样式，不在局部组件建立冲突配色。
- 浅色主题默认使用透明背景、深色边框和 `var(--ink)` 文字；默认态不使用主题色背景配白字。
- 悬停时背景与边框切换为 `var(--accent)`，文字和图标切换为白色。
- 暗色主题使用同一组语义变量，不硬编码浅色主题颜色。
- 持久选中、展开、危险和禁用状态可以使用各自明确的语义状态，但必须与普通悬停区分。
- 每个新增或修改的操作必须检查默认、悬停、键盘焦点、禁用和持久状态。

## 内容可达性与滚动

- 布局优先通过弹性尺寸、响应式网格和换行适应可用空间；内容无法合理重排时才使用内部滚动。
- 需要承载超出内容的页面、面板和弹窗内容区使用 `overflow: auto` 或对应方向的 `overflow-x/overflow-y: auto`。
- 隐藏滚动条只隐藏轨道和滑块，不取消滚轮、触控板、键盘或触屏滚动。
- `overflow: hidden` 只用于明确视觉裁剪，或外层固定且内层已有独立滚动容器的布局。
- 固定数量的状态看板分栏不得依赖横向滚动展示。
- 弹窗和全屏布局必须能够滚动到全部内容和操作按钮。

## 验收范围

- 新增或修改用户界面必须验证默认、悬停、焦点、禁用、选中、展开、加载、空状态和错误状态。
- 桌面视口下全部内容和操作必须可达。
- 明暗主题都必须保持信息层级、对比度和交互反馈。
- 移动端单独适配不作为当前视觉交付门，但不得通过隐藏内容破坏基本可达性。
