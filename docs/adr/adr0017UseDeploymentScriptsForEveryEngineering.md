# 所有工程统一使用部署脚本

工程环境保存显示名称和稳定标识。每个绑定工程在本机固定路径 `.xapt/README.md` 维护执行约定，负责定义准备、部署和验收入口；`.xapt` 按 Git 忽略规则保留在本机，不强制加入提交。xapt 准备工作区时复用已有忽略内容共享机制，Skill 与 xapt 直接读取工作区中的该文件，无需修改 `AGENTS.md`。执行期间配置只读，使用内容 SHA-256 标识并在配置变化后重新核验证据。PersonAgent 与 AgentParty 均按冻结的环境标识使用对应工程的约定。

更新完成集成、验证、适用评审和正式产物准备后，确认所有所需普通 Push，再运行各工程环境的部署入口。成功以本机观察到的脚本退出、提交和产物验收回执为准。恢复先按同一约定只读核对实际版本。工程可以选择适用的运行时、构建输入和已有缓存，xapt 只校验通用证据。

取消 CI/CD 部署模式时已退出仅 Push 的业务终态、等待外部部署报告及其专用界面。Schema 35 继续移除平台旧命令配置，由离线预检处理活动执行和环境身份映射。旧 Task 保留原 Bundle，历史部署结果保留当时的证据含义。
