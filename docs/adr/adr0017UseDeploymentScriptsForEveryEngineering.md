# 所有工程统一使用部署脚本

工程环境保存显示名称和稳定标识。工程在根目录的 Agent 入口指向一份执行约定，负责定义本地准备、部署和验收入口。PersonAgent 与 AgentParty 均按冻结的环境标识使用对应工程的约定。

更新完成集成、验证、适用评审和正式产物准备后，确认所有所需普通 Push，再运行各工程环境的部署入口。成功以本机观察到的脚本退出、提交和产物验收回执为准。恢复先按同一约定只读核对实际版本。工程可以选择适用的运行时、构建输入和已有缓存，xapt 只校验通用证据。

取消 CI/CD 部署模式时已退出仅 Push 的业务终态、等待外部部署报告及其专用界面。Schema 35 继续移除平台旧命令配置，由离线预检处理活动执行和环境身份映射。旧 Task 保留原 Bundle，历史部署结果保留当时的证据含义。
