# 所有工程统一使用部署脚本

工程环境只配置部署脚本，取消 CI/CD 部署模式；这一决定同时适用于 PersonAgent 和 AgentParty。部署统一由 Codex 在本机完成，代价是不再提供 Push 后等待负责人回报外部流水线结果的交付方式。

更新仍须完成集成、验证、适用评审和普通 Git Push，确认推送成功后执行配置的脚本，取得脚本及工程要求的部署验收结果后才算成功。移除的是 `CI_CD`、仅 Push 的业务终态 `PUSHED`、`WAITING_EXTERNAL`、外部部署报告及其专用输入输出、状态和界面；Git Push 和推送证据继续保留。通用人工审批、问答及原会话交接不属于本项移除范围。

此决定尚未实现。工程契约、数据库、Web、xapt 的结果契约及 `x-skills` 中的 XUpdate 必须协调切换；旧会话仍绑定旧 Skill Bundle。旧 CI/CD 配置可能没有真实部署命令，历史 `PUSHED` 也不代表部署成功，不能用占位脚本或伪造完成状态转换。旧配置、未完成任务与历史数据的切换须在实施前明确处置，不增加运行时兼容分支。
