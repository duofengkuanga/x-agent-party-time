# 通用平台与提测业务分开，页面就近组织

项目、工程配置和 Agent 管理是可供多种业务使用的通用能力，提测、缺陷处理、修复、更新、验证与关闭构成具体业务。取消 Cooking 作为这些能力的总名称：Web 使用 `app/(pages)` 组织页面及其组件、样式，保留独立的 Actions 和 HTTP 接入；`server/platform` 承载通用能力，`server/submissions` 承载提测业务，`contracts` 承载纯数据交换定义。

页面入口与界面放在一起，避免为每页增加一次跨目录跳转；界面和服务端实现仍有明确职责。通用模块不直接认识提测状态，通过 `runtime` 注入真实业务引用和删除参与者。该决定延续 ADR-0001 的领域无关执行能力与 ADR-0002 的本机路径边界；既有 ADR 中 Cooking 对具体交付流程的描述对应新的提测模块。

数据库以 Schema 31 同步调整模块归属，通过独立离线迁移保留历史记录。27/28 的既有结果转换仍只在迁移中执行，29/30 可以保留活动任务；命名迁移只转换明确的表、索引、外键目标及 Execution owner namespace，历史 JSON、幂等回执、附件和业务事实保持原样。新版只使用新结构，不增加运行时兼容分支或旧入口转发。
